Unity Slot Machine Game

A simple Slot Machine game built using Unity and deployed using WebGL on GitHub Pages.

Live Demo
Play Here:  
https://mandarm14.github.io/MyUnityWebGLGame/

---

Built With

- Unity (WebGL Build)
- C#
- Git & GitHub
- GitHub Pages (Deployment)

---

Game Features

- 3 Reel Slot Machine System
- Random Symbol Generation
- Win/Loss Detection Logic
- Simple UI with Spin Button
- Popup Result Display
- Clean WebGL Deployment

---

How To Play

1. Click the **Spin** button.
2. Wait for reels to stop.
3. If all 3 symbols match → You Win 🎉
4. Otherwise → Try Again!
